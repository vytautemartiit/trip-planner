# 🎫 Trip Budget Planner

A full-stack application that helps plan trips within a budget — for single or multi-country journeys, with real-time currency conversion.

**[🔗 View demo]()**

## Why this project?

Most flight search tools (Skyscanner, etc.) search a single A→B route. This project solves a different problem: **"I have €500 and 8 days — where and how far can I travel, visiting multiple countries?"**

## Features

- 🔍 Search by budget and trip duration
- 🌍 Multi-country (2–3) combination generation and cost calculation
- 💱 Real-time currency conversion (Frankfurter API, ECB rates)
- 🎨 Custom UI design ("boarding pass" theme)

## Tech Stack

**Backend**
- Python 3.12, FastAPI, Uvicorn
- Frankfurter API (currency rates)

**Frontend**
- React 19 (Vite)
- CSS (no UI libraries — hand-built design)

## Architecture
frontend (React) → backend (FastAPI) → Frankfurter API (currency)
↓
data.py (destination data)


The backend calculates trip cost using this formula:

total = flight_price + (hotel_per_night × nights) + (daily_cost × days)
For multi-country search, `itertools.combinations` generates every possible country combination, calculates total cost for each, and filters by budget.

## API Endpoints

| Endpoint | Description |
|---|---|
| `GET /search?budget=&days=` | Single-country search |
| `GET /search-multi?budget=&days=&countries=` | Multi-country combinations |

Full interactive docs available at `/docs` (Swagger UI, auto-generated by FastAPI).

## Running locally

**Backend:**
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install fastapi uvicorn requests
uvicorn main:app --reload --port 8000
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

## Known limitations / next steps

- Destination prices are currently static (`data.py`) — real, live flight price APIs (Amadeus, Kiwi) became difficult to access for free in 2026 without high user volume or business agreements.
- Days are split evenly between countries — a smarter (e.g. dynamic programming) split could reduce total cost.
- Possible additions: accommodation type selection, trip route map visualization, user accounts for saved trips.

## Funkcionalumas

- 🔍 Paieška pagal biudžetą ir kelionės trukmę
- 🌍 Kelių šalių (2–3) kombinacijų generavimas ir kainų skaičiavimas
- 💱 Realaus laiko valiutos konvertavimas (Frankfurter API, ECB kursai)
- 🎨 Savitas UI dizainas ("boarding pass" tema)

## Tech Stack

**Backend**
- Python 3.12, FastAPI, Uvicorn
- Frankfurter API (valiutų kursai)

**Frontend**

## Architektūra
frontend (React) → backend (FastAPI) → Frankfurter API (valiutos)
